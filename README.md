# 🐍 Snake Game (Python Turtle)

This is a classic **Snake Game** implemented in **Python** using the built-in `turtle` graphics module. The game features smooth movement, food collision, score tracking, and increasing speed as the snake grows longer.

---

## 🎮 Game Features

- Snake movement using keyboard controls
- Food appears at random positions
- Snake grows when food is eaten
- Collision detection:
  - Wall collision resets the game
  - Self-collision resets the game
- Score and High Score tracking
- Increasing difficulty (speed increases)

---

## ⌨️ Controls

| Key | Action |
|----|--------|
| **W** | Move Up |
| **S** | Move Down |
| **A** | Move Left |
| **D** | Move Right |

---

## 🛠️ Requirements

- Python 3.x  
- No external libraries required (uses built-in modules)
